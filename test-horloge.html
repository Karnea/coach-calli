Diagnostic minuteur Horloge

Appuie sur chaque bouton l'un après l'autre. Note lequel (ou lesquels) ouvre directement l'app Horloge avec un minuteur de 30 s. Dis-moi le ou les numéros qui marchent.

1Package Google + fallback
Méthode actuelle de l'app. Cible com.google.android.deskclock.
Test 1 — package Google
2SANS package, SANS fallback
Laisse Android choisir l'app. Si aucune horloge, Chrome affiche une erreur (normal).
Test 2 — sans package
3SANS package + SKIP_UI=true
Skip_ui laisse l'horloge démarrer sans écran de config.
Test 3 — sans package, skip_ui
4Scheme direct (deskclock)
Certaines ROM exposent un scheme propre.
Test 4 — component explicite
5Réveil au lieu de minuteur (SET_ALARM)
Juste pour voir si une AUTRE action horloge fonctionne, elle.
Test 5 — SET_ALARM (réveil 7h30)

Une fois que tu sais quels tests marchent, reviens me le dire. On corrigera l'app avec la méthode qui fonctionne sur ton Pixel.
